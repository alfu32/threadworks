# Threadwork

## Product name

Threadwork

## Description

Threadwork는 연결된 워크플로로 소프트웨어 시스템을 설계하고 검사하고 컴파일하고 문서화하는 토폴로지 중심의 데스크톱 IDE입니다.

소프트웨어 아키텍처, 데이터 흐름, 구현, 프로젝트 관리를 하나의 시각적 개발 환경으로 통합합니다. 연결된 노드와 링크로 시스템을 설계하고, 타입이 있는 데이터 채널을 정의하며, 컴포넌트를 복합 구조로 구성하고 네트워크에서 정보가 이동하는 방식을 확인할 수 있습니다.

컴파일러 인식 구문 강조, 코드 인텔리전스, 선언 정보, 생성된 런타임 지원, 언어별 기본 타입을 사용해 모델 안에서 구현 코드를 직접 편집하세요. 컴파일러 템플릿과 재사용 가능한 아키타입으로 모델에서 프로젝트 파일을 생성할 수 있습니다.

프로젝트 관리 화면에서는 상태, 담당자, 책임자, 수정 기록, 상태 전환을 관리합니다. 네트워크 분석은 생성, 실행, 의존성, 사용 관계를 측정하며 원시 P/E/D/U 행렬로 구조, 결합도, 도달 가능성, 최적화 기회를 확인합니다.

Threadwork는 C, Go, Kotlin, JavaScript, PHP, QuickJS 워크플로, 타입이 있는 객체 필드, 배열, 맵, 모델 정의 타입, 문서 생성, 로컬 프로젝트 저장을 지원합니다.

## What’s new

- 생성, 실행, 의존성, 사용 지표를 포함한 네트워크 분석을 추가했습니다.
- 끝점 선택과 반응형 레이아웃을 지원하는 원시 P/E/D/U 행렬을 추가했습니다.
- 편집 성능을 위해 필요한 경우에만 분석을 다시 계산합니다.
- 링크와 모델 필드에 컴파일러 인식 배열 및 맵 타입을 추가했습니다.
- 모델 정의 타입을 맵 키 타입으로 선택할 수 있습니다.
- OAuth, 브라우저 복귀, MSIX와 Snap 패키징, Windows 아이콘, 릴리스 자동화를 개선했습니다.
- Node.js 컴파일러의 클린 빌드를 수정했습니다.
