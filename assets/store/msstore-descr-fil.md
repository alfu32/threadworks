# Threadwork

## Product name

Threadwork

## Description

Ang Threadwork ay isang desktop IDE na inuuna ang topology para sa pagdidisenyo, pagsusuri, pag-compile, at pagdodokumento ng mga software system bilang magkakaugnay na workflow.

Pinagsasama ng Threadwork ang software architecture, data flow, implementation, at project management sa isang visual na development environment. Magdisenyo gamit ang magkakaugnay na node at link, magtakda ng typed data channel, mag-ayos ng mga component bilang composite, at suriin ang daloy ng impormasyon sa network.

Mag-edit ng implementation code sa loob mismo ng model gamit ang compiler-aware syntax highlighting, code intelligence, declaration details, generated runtime support, at language-specific primitive types. Gumamit ng compiler template at reusable archetype para gawing generated project files ang model.

May status, assignment, responsibility, revision history, at state transition ang project management view. Sinusukat ng network analysis ang production, execution, dependency, at usage relationships, kasama ang raw P/E/D/U matrices para makita ang structure, coupling, reachability, at optimization opportunities.

Sinusuportahan ng Threadwork ang C, Go, Kotlin, JavaScript, PHP, at QuickJS workflows, typed object fields, arrays, maps, model-defined types, documentation generation, at local project storage.

## What’s new

- Nagdagdag ng network analysis para sa production, execution, dependency, at usage metrics.
- Nagdagdag ng raw P/E/D/U matrix views na may selectable endpoints at responsive layout.
- Ipinagpaliban ang recalculation ng analysis hanggang kailangan upang manatiling mabilis ang editing.
- Nagdagdag ng compiler-aware array at map types para sa links at model fields.
- Maaaring gamitin ang model-defined types bilang map key types.
- Pinahusay ang OAuth, browser fallback, MSIX at Snap packaging, Windows icons, at release automation.
- Inayos ang clean build support ng Node.js compiler.
