# Threadwork

## Product name

Threadwork

## Description

Threadwork एक topology-first desktop IDE है, जो जुड़े हुए workflows के रूप में software systems को design, inspect, compile और document करने के लिए बनाई गई है।

Threadwork software architecture, data flow, implementation और project management को एक visual development environment में जोड़ता है। जुड़े हुए nodes और links से systems बनाएं, typed data channels परिभाषित करें, components को composites में व्यवस्थित करें और network में information flow देखें।

Compiler-aware syntax highlighting, code intelligence, declaration details, generated runtime support और language-specific primitive types के साथ model के अंदर implementation code संपादित करें। Model से generated project files बनाने के लिए compiler templates और reusable archetypes का उपयोग करें।

Project management view में statuses, assignments, responsibility, revision history और state transitions शामिल हैं। Network analysis production, execution, dependency और usage relationships को मापता है और raw P/E/D/U matrices के माध्यम से structure, coupling, reachability और optimization opportunities दिखाता है।

Threadwork C, Go, Kotlin, JavaScript, PHP और QuickJS workflows, typed object fields, arrays, maps, model-defined types, documentation generation और local project storage का समर्थन करता है।

## What’s new

- Production, execution, dependency और usage metrics के साथ network analysis जोड़ा गया।
- Selectable endpoints और responsive layout के साथ raw P/E/D/U matrix views जोड़े गए।
- Editing को तेज रखने के लिए analysis recalculation को आवश्यकता तक स्थगित किया गया।
- Links और model fields के लिए compiler-aware array और map types जोड़े गए।
- Model-defined types को map key types के रूप में चुना जा सकता है।
- OAuth, browser fallback, MSIX और Snap packaging, Windows icons और release automation में सुधार।
- Node.js compiler के clean build support को ठीक किया गया।
