# Threadwork

## Product name

Threadwork

## Description

Threadwork is a topology-first desktop IDE for designing, inspecting, compiling, and documenting software systems as connected workflows.

Threadwork keeps software architecture, data flow, implementation, and project management in one visual development environment. Design systems as connected nodes and links, define typed data channels, organize components into composites, and inspect how information moves through the network.

Edit implementation code directly inside the model with compiler-aware syntax highlighting, code intelligence, declaration details, generated runtime support, and language-specific primitive types. Use compiler template sets and reusable archetypes to move from a model to generated project files.

The project management view adds statuses, assignments, responsibility, revision history, and state transitions. Network analysis measures production, execution, dependency, and usage relationships, with raw P/E/D/U matrices that help identify structure, coupling, reachability, and optimization opportunities.

Threadwork supports C, Go, Kotlin, JavaScript, PHP, and QuickJS workflows, typed object fields, arrays, maps, model-defined types, documentation generation, and local project storage. It is designed for developers who want a software system's workflow and structure to remain visible beside its implementation.
