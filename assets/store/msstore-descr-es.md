# Threadwork

## Product name

Threadwork

## Description

Threadwork es un IDE de escritorio centrado en la topología para diseñar, inspeccionar, compilar y documentar sistemas de software como flujos de trabajo conectados.

Threadwork reúne arquitectura de software, flujo de datos, implementación y gestión de proyectos en un entorno de desarrollo visual. Diseña con nodos y enlaces conectados, define canales de datos tipados, organiza componentes en compuestos e inspecciona cómo circula la información por la red.

Edita el código de implementación directamente en el modelo con resaltado consciente del compilador, inteligencia de código, detalles de declaraciones, soporte de runtime generado y tipos primitivos específicos del lenguaje. Usa plantillas de compilador y arquetipos reutilizables para pasar del modelo a los archivos generados del proyecto.

La vista de gestión incluye estados, asignaciones, responsables, historial de revisiones y transiciones de estado. El análisis de red mide relaciones de producción, ejecución, dependencia y uso, con matrices P/E/D/U sin procesar para identificar estructura, acoplamiento, alcanzabilidad y oportunidades de optimización.

Threadwork admite flujos de trabajo en C, Go, Kotlin, JavaScript, PHP y QuickJS, campos de objetos tipados, arrays, mapas, tipos definidos en el modelo, generación de documentación y almacenamiento local de proyectos.

## What’s new

- Añadido análisis de red con métricas de producción, ejecución, dependencia y uso.
- Añadidas vistas de matrices P/E/D/U sin procesar con selección de extremos y diseño adaptable.
- El análisis se recalcula solo cuando es necesario para mantener la edición fluida.
- Añadidos tipos array y map conscientes del compilador para enlaces y campos.
- Los tipos definidos en el modelo pueden usarse como claves de mapas.
- Mejorados OAuth, el retorno del navegador, los paquetes MSIX y Snap, los iconos de Windows y la automatización de versiones.
- Corregida la compilación limpia del compilador Node.js.
