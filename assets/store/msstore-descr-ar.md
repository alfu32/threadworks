# Threadwork

## Product name

Threadwork

## Description

Threadwork هو بيئة تطوير مكتبية تضع الطوبولوجيا في المقام الأول لتصميم أنظمة البرمجيات وفحصها وتجميعها وتوثيقها باعتبارها مسارات عمل مترابطة.

يجمع Threadwork بين بنية البرمجيات وتدفق البيانات والتنفيذ وإدارة المشروع في مساحة مرئية واحدة. صمّم الأنظمة باستخدام عقد وروابط مترابطة، وعرّف قنوات بيانات ذات أنواع، ونظّم المكونات داخل مكونات مركبة، وافحص حركة المعلومات عبر الشبكة.

حرّر كود التنفيذ داخل النموذج مباشرة مع تلوين واعٍ بالمترجم، وذكاء للكود، وتفاصيل التعريفات، ودعم لبيئة التشغيل المولدة، وأنواع أولية خاصة بكل لغة. استخدم قوالب المترجمات والأنماط القابلة لإعادة الاستخدام للانتقال من النموذج إلى ملفات المشروع المولدة.

تضيف إدارة المشروع الحالات والتكليف والمسؤولية وسجل المراجعات وانتقالات الحالة. يقيس تحليل الشبكة علاقات الإنتاج والتنفيذ والاعتماد والاستخدام، مع مصفوفات P/E/D/U خام تساعد على فهم البنية والاقتران وإمكانية الوصول وفرص التحسين.

يدعم Threadwork مسارات C وGo وKotlin وJavaScript وPHP وQuickJS، وحقول الكائنات المكتوبة والمصفوفات والخرائط والأنواع المعرفة في النموذج وتوليد التوثيق والتخزين المحلي للمشروعات.

## What’s new

- إضافة تحليل الشبكة مع مقاييس الإنتاج والتنفيذ والاعتماد والاستخدام.
- إضافة عروض مصفوفات P/E/D/U الخام مع تحديد نقاط النهاية وتخطيط متجاوب.
- تأجيل إعادة حساب التحليل حتى الحاجة للحفاظ على سرعة التحرير.
- إضافة أنواع المصفوفات والخرائط للروابط وحقول النموذج.
- إتاحة الأنواع المعرفة في النموذج كمفاتيح للخرائط.
- تحسين OAuth وفتح المتصفح وحزم MSIX وSnap وتوليد أيقونات Windows.
- إصلاح البناء النظيف لمترجم Node.js وأتمتة الإصدارات.
