# Threadwork

## Product name

Threadwork

## Description

Threadwork ਇੱਕ topology-first desktop IDE ਹੈ ਜੋ ਜੁੜੇ ਹੋਏ workflows ਵਜੋਂ software systems ਨੂੰ design, inspect, compile ਅਤੇ document ਕਰਨ ਲਈ ਹੈ।

Threadwork software architecture, data flow, implementation ਅਤੇ project management ਨੂੰ ਇੱਕ visual development environment ਵਿੱਚ ਜੋੜਦਾ ਹੈ। ਜੁੜੇ nodes ਅਤੇ links ਨਾਲ systems ਬਣਾਓ, typed data channels ਪਰਿਭਾਸ਼ਿਤ ਕਰੋ, components ਨੂੰ composites ਵਿੱਚ ਵਿਵਸਥਿਤ ਕਰੋ ਅਤੇ network ਵਿੱਚ information flow ਦੀ ਜਾਂਚ ਕਰੋ।

Compiler-aware syntax highlighting, code intelligence, declaration details, generated runtime support ਅਤੇ language-specific primitive types ਨਾਲ model ਦੇ ਅੰਦਰ implementation code edit ਕਰੋ। Model ਤੋਂ generated project files ਬਣਾਉਣ ਲਈ compiler templates ਅਤੇ reusable archetypes ਵਰਤੋ।

Project management view ਵਿੱਚ statuses, assignments, responsibility, revision history ਅਤੇ state transitions ਹਨ। Network analysis production, execution, dependency ਅਤੇ usage relationships ਨੂੰ ਮਾਪਦਾ ਹੈ ਅਤੇ raw P/E/D/U matrices ਰਾਹੀਂ structure, coupling, reachability ਅਤੇ optimization opportunities ਦਿਖਾਉਂਦਾ ਹੈ।

Threadwork C, Go, Kotlin, JavaScript, PHP ਅਤੇ QuickJS workflows, typed object fields, arrays, maps, model-defined types, documentation generation ਅਤੇ local project storage ਨੂੰ support ਕਰਦਾ ਹੈ।

## What’s new

- Production, execution, dependency ਅਤੇ usage metrics ਨਾਲ network analysis ਜੋੜਿਆ ਗਿਆ।
- Selectable endpoints ਅਤੇ responsive layout ਵਾਲੇ raw P/E/D/U matrix views ਜੋੜੇ ਗਏ।
- Editing ਨੂੰ ਤੇਜ਼ ਰੱਖਣ ਲਈ analysis recalculation ਨੂੰ ਲੋੜ ਤੱਕ ਮੁਲਤਵੀ ਕੀਤਾ ਗਿਆ।
- Links ਅਤੇ model fields ਲਈ compiler-aware array ਅਤੇ map types ਜੋੜੇ ਗਏ।
- Model-defined types ਨੂੰ map key types ਵਜੋਂ ਚੁਣਿਆ ਜਾ ਸਕਦਾ ਹੈ।
- OAuth, browser fallback, MSIX ਅਤੇ Snap packaging, Windows icons ਅਤੇ release automation ਵਿੱਚ ਸੁਧਾਰ।
- Node.js compiler ਦਾ clean build support ਠੀਕ ਕੀਤਾ ਗਿਆ।
