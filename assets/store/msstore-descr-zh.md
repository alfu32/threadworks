# Threadwork

## Product name

Threadwork

## Description

Threadwork 是一款以拓扑为核心的桌面集成开发环境，用于将软件系统设计、检查、编译和文档化为相互连接的工作流。

Threadwork 将软件架构、数据流、实现和项目管理统一在一个可视化开发环境中。使用相互连接的节点和链接设计系统，定义带类型的数据通道，将组件组织为复合组件，并检查信息在网络中的流动。

可直接在模型中编辑实现代码，获得编译器感知的语法高亮、代码智能、声明详情、生成的运行时支持以及语言专属的基本类型。使用编译器模板和可复用原型，将模型转换为生成的项目文件。

项目管理视图提供状态、分配、负责人、修订历史和状态转换。网络分析测量生产、执行、依赖和使用关系，并提供原始 P/E/D/U 矩阵，帮助发现结构、耦合、可达性和优化机会。

Threadwork 支持 C、Go、Kotlin、JavaScript、PHP 和 QuickJS 工作流，支持类型化对象字段、数组、映射、模型定义类型、文档生成和本地项目存储。

## What’s new

- 新增生产、执行、依赖和使用指标的网络分析。
- 新增可选择端点且支持响应式布局的原始 P/E/D/U 矩阵。
- 仅在需要时重新计算分析，保持编辑流畅。
- 为链接和模型字段新增编译器感知的数组和映射类型。
- 支持使用模型定义类型作为映射键类型。
- 改进 OAuth、浏览器回退、MSIX、Snap、Windows 图标和发布自动化。
- 修复 Node.js 编译器的干净构建支持。
