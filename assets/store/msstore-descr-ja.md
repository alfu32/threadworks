# Threadwork

## Product name

Threadwork

## Description

Threadwork は、接続されたワークフローとしてソフトウェアシステムを設計、検査、コンパイル、文書化するための、トポロジーを中心にしたデスクトップ IDE です。

ソフトウェアアーキテクチャ、データフロー、実装、プロジェクト管理をひとつのビジュアル開発環境にまとめます。接続されたノードとリンクでシステムを設計し、型付きデータチャネルを定義し、コンポーネントを複合体として整理し、ネットワーク上の情報の流れを確認できます。

コンパイラー対応の構文ハイライト、コードインテリジェンス、宣言の詳細、生成ランタイム、言語固有のプリミティブ型を使って、モデル内で実装コードを直接編集できます。コンパイラーテンプレートと再利用可能なアーキタイプで、モデルからプロジェクトファイルを生成します。

プロジェクト管理では、ステータス、担当者、責任者、リビジョン履歴、状態遷移を管理できます。ネットワーク分析は生成、実行、依存、使用の関係を測定し、P/E/D/U 行列で構造、結合、到達可能性、最適化の機会を確認できます。

C、Go、Kotlin、JavaScript、PHP、QuickJS、型付きオブジェクトフィールド、配列、マップ、モデル定義型、ドキュメント生成、ローカルプロジェクト保存に対応しています。

## What’s new

- 生成、実行、依存、使用の指標を含むネットワーク分析を追加。
- 端点選択とレスポンシブレイアウトに対応した P/E/D/U 行列を追加。
- 編集の応答性を保つため、分析の再計算を必要時に限定。
- リンクとモデルフィールドにコンパイラー対応の配列・マップ型を追加。
- モデル定義型をマップのキー型として選択可能に改善。
- OAuth、ブラウザー復帰、MSIX、Snap、Windows アイコン、リリース自動化を改善。
- Node.js コンパイラーのクリーンビルドを修正。
