# Threadwork

## Product name

Threadwork

## Description

Threadwork é uma IDE desktop orientada à topologia para projetar, inspecionar, compilar e documentar sistemas de software como fluxos de trabalho conectados.

Threadwork reúne arquitetura de software, fluxo de dados, implementação e gerenciamento de projetos em um ambiente visual de desenvolvimento. Crie sistemas com nós e links conectados, defina canais de dados tipados, organize componentes em compostos e examine o caminho das informações pela rede.

Edite o código de implementação diretamente no modelo com realce de sintaxe orientado ao compilador, inteligência de código, detalhes de declarações, suporte de runtime gerado e tipos primitivos específicos da linguagem. Use modelos de compilador e arquétipos reutilizáveis para transformar o modelo em arquivos de projeto.

A gestão de projetos inclui status, atribuições, responsáveis, histórico de revisões e transições de estado. A análise de rede mede relações de produção, execução, dependência e uso, com matrizes P/E/D/U brutas para revelar estrutura, acoplamento, alcançabilidade e oportunidades de otimização.

Threadwork oferece suporte a fluxos de trabalho em C, Go, Kotlin, JavaScript, PHP e QuickJS, campos de objetos tipados, arrays, mapas, tipos definidos no modelo, geração de documentação e armazenamento local de projetos.

## What’s new

- Adicionada análise de rede com métricas de produção, execução, dependência e uso.
- Adicionadas visualizações de matrizes P/E/D/U brutas com seleção de extremos e layout responsivo.
- O recálculo da análise agora ocorre somente quando necessário, mantendo a edição rápida.
- Adicionados tipos array e map orientados ao compilador para links e campos.
- Tipos definidos no modelo podem ser usados como chaves de mapas.
- Melhorados OAuth, retorno do navegador, empacotamento MSIX e Snap, ícones do Windows e automação de releases.
- Corrigido o build limpo do compilador Node.js.
