# Threadwork

## Product name

Threadwork

## Description

Threadwork هڪ topology-first desktop IDE آهي جيڪا ڳنڍيل workflows طور software systems کي design، inspect، compile ۽ document ڪرڻ لاءِ ٺاهي وئي آهي.

Threadwork software architecture، data flow، implementation ۽ project management کي هڪ visual development environment ۾ گڏ ڪري ٿو. ڳنڍيل nodes ۽ links سان systems ٺاهيو، typed data channels مقرر ڪريو، components کي composites ۾ ترتيب ڏيو ۽ network ۾ information flow ڏسو.

Compiler-aware syntax highlighting، code intelligence، declaration details، generated runtime support ۽ language-specific primitive types سان model اندر implementation code edit ڪريو. Model مان generated project files ٺاهڻ لاءِ compiler templates ۽ reusable archetypes استعمال ڪريو.

Project management view ۾ statuses، assignments، responsibility، revision history ۽ state transitions شامل آهن. Network analysis production، execution، dependency ۽ usage relationships کي ماپي ٿو ۽ raw P/E/D/U matrices ذريعي structure، coupling، reachability ۽ optimization opportunities ظاهر ڪري ٿو.

Threadwork C، Go، Kotlin، JavaScript، PHP ۽ QuickJS workflows، typed object fields، arrays، maps، model-defined types، documentation generation ۽ local project storage کي support ڪري ٿو.

## What’s new

- Production، execution، dependency ۽ usage metrics سان network analysis شامل ڪيو ويو.

- OAuth، browser fallback، MSIX ۽ Snap packaging، Windows icons ۽ release automation بهتر ڪيا ويا.
- Node.js compiler جي clean build support کي درست ڪيو ويو.
